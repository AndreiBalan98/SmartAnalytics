================================================================================
  🎯 KEY ARCHITECTURAL DECISIONS
================================================================================

1. Meta IDs as Primary Keys
   - Direct mapping (e.g., "act_123456789")
   - No external_id fields needed

2. SyncState as Source of Truth
   - Tracks every sync operation
   - Enables incremental sync
   - Records errors

3. Append-Only Insights
   - No unique constraints
   - Preserves all data points
   - Time-series analysis ready

4. Permission Filtering
   - Enforced at backend query level
   - Row-level security
   - Clients ONLY see permitted accounts

5. 3-Panel Layout
   - Responsive design
   - Modular components
   - Clean separation
